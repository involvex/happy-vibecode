BridgeAgent Durable Object

The BridgeAgent (defined in apps/web/worker/bridge-agent.ts) is a Cloudflare Durable Object that manages real-time WebSocket connections between clients and CLI agents.

Responsibilities

  • WebSocket connection lifecycle (connect, message, disconnect)
  • Message relay between web/mobile clients and CLI agents
  • Connection state tracking (connecting, connected, disconnected, error)
  • Per-room isolation (one agent session per roomId)
  • SQLite-backed state persistence

WebSocket Path

WebSocket URL 
wss://your-worker.workers.dev/agents/BridgeAgent/<roomId>?token=<api-token>
Authentication
WebSocket connections require a valid API token passed as a token query parameter (for browser clients) or Authorization: Bearer <token> header (for CLI/mobile clients).
