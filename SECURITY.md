# Security Policy

The security of our project is paramount. We are committed to addressing security vulnerabilities in a responsible and timely manner.

## Vulnerability Reporting

If you discover a security vulnerability in this project, please report it to us as soon as possible. We will investigate and address all valid reports promptly.

**Please do not disclose vulnerabilities publicly until they have been resolved.**

## Supported Versions

The following versions are actively maintained: 0.0.x.

## Disclosure Policy

We follow a responsible disclosure policy. Once a vulnerability is reported, we will:

1. Acknowledge receipt of the report.
2. Investigate the vulnerability.
3. Develop and test a fix.
4. Release the fix.
5. Publicly disclose the vulnerability (if appropriate and agreed upon) after the fix is released.
